### COSC2007 – Data Structures II
# Assignment: Mini Search Engine

## 🎯 Introduction & Objective

Search engines help users find information in large collections of documents. Instead of reading every document for each search, a search engine builds an **inverted index**: a dictionary that maps each word to the documents containing it. This is the basic idea behind document search, website search, and searching digital libraries.

In this assignment, build a **mini search engine in Java** that adds and removes text documents, counts word occurrences, supports **AND/OR searches**, and **ranks results**. You will use Java dictionaries (`Map`/`HashMap`) to solve these problems, **not implement a dictionary or hash table from scratch**.

!!! abstract "Learning Objectives"
    - Use **nested dictionaries** to index words and documents.
    - Combine dictionary results using **set union and intersection**.
    - Keep indexes accurate when documents are **replaced or removed**.
    - Sort search results and calculate simple **relevance scores**.

## 📋 Dictionary Design

Two dictionaries are provided in the starter code:

```java
Map<String, Map<String, Integer>> documentIndex; // document ID -> (word -> count)
Map<String, Map<String, Integer>> invertedIndex; // word -> (document ID -> count)
```

For `D1 = "Java java data"`, they include:

```text
documentIndex: D1   -> {java=2, data=1}
invertedIndex: java -> {D1=2}
               data -> {D1=1}
```

Maintain **both** indexes whenever you add, replace, or remove documents.

## 💻 Required Methods (Inputs & Outputs)

For the examples below, assume the engine initially contains:

```java
engine.addDocument("D1", "Java java data");
engine.addDocument("D2", "Data search fast");
engine.addDocument("D3", "Java search");
```

**Each table example is independent** (start from the three documents above; do not run the rows one after another).

| Method | Input and expected result |
|---|---|
| `void addDocument(String id, String content)` | **Input:** ID and document text. `addDocument("D4", "Java!")` adds D4 and returns nothing (`void`). If the ID already exists, replace its old document completely. |
| `boolean removeDocument(String id)` | **Input:** document ID. `removeDocument("D2")` returns `true` and removes D2; removing an unknown ID returns `false`. |
| `int getWordFrequency(String word, String documentId)` | **Input:** one word and an ID. `getWordFrequency("JAVA!", "D1")` returns `2`; an absent word/document returns `0`. |
| `List<String> searchAND(String[] queryWords)` | **Input:** query terms. `searchAND(new String[]{"java", "data"})` returns `[D1]` because D1 contains **both** words. |
| `List<String> searchOR(String[] queryWords)` | **Input:** query terms. `searchOR(new String[]{"java", "search"})` returns `[D1, D2, D3]` because each contains **at least one** word. |
| `List<String> rankDocuments(String[] queryWords)` | **Input:** query terms. `rankDocuments(new String[]{"java", "search"})` returns `[D1, D3, D2]`: scores are 2, 2, and 1; ties use alphabetical ID order. |
| `int getDocumentCount()` | **Input:** none. Returns `3`, including any documents that contain no words. |
| `int getVocabularySize()` | **Input:** none. Returns `4`: the distinct indexed words are `java`, `data`, `search`, and `fast`. |

!!! warning "Input rules"
    - **Document IDs:** Case-sensitive; `"D1"` and `"d1"` are different. A null or blank ID throws `IllegalArgumentException`. IDs are otherwise preserved as supplied.
    - **Document text:** Null throws `IllegalArgumentException`. Empty or punctuation-only documents are valid and count as documents.
    - **Words:** Extract sequences of English letters/digits (`[A-Za-z0-9]+`) and convert to lowercase. Punctuation separates words: `"Java, JAVA!"` becomes `java` twice; `"don't"` becomes `don` and `t`.
    - **Query arrays:** An array item may contain multiple words. Ignore null items and punctuation-only items; treat duplicate query terms **once**. A null query array throws `IllegalArgumentException`.
    - **Frequency lookup:** A null `word`, or one containing more than one word after tokenization, throws `IllegalArgumentException`. Punctuation-only `word` returns `0`.
    - **Result order:** AND/OR results are sorted by document ID (ascending, case-sensitive lexicographic order). Ranking sorts by **highest total frequency** of distinct query words, then ascending ID for ties. No matches return `[]`.

!!! warning "Index consistency"
    Replacing or removing a document must remove its old entries from **both indexes**. If a word no longer appears in any document, remove that word from the inverted index. A document with no words must still count toward `getDocumentCount()`.

## 🧪 Sample Run 2 – Longer Documents, Removal & Replacement

```java
MiniSearchEngine engine = new MiniSearchEngine();

engine.addDocument("D1",
    "Search engines organize large collections of documents. " +
    "A search engine builds an index so users can find relevant documents quickly. " +
    "An index helps search engines avoid scanning every document.");
engine.addDocument("D2",
    "Java dictionaries store keys and values. " +
    "A dictionary can count words in documents and help build a search index. " +
    "Java maps make dictionary lookups convenient.");
engine.addDocument("D3",
    "Students explore algorithms through practical projects. " +
    "Search algorithms compare possible results, while ranking algorithms order documents by relevance. " +
    "Effective search depends on indexing and accurate word counts.");

System.out.println("Documents: " + engine.getDocumentCount());
System.out.println("D1 search frequency: " + engine.getWordFrequency("search", "D1"));
System.out.println("D1 index frequency: " + engine.getWordFrequency("index", "D1"));
System.out.println("AND(search, algorithms): " +
    engine.searchAND(new String[]{"search", "algorithms"}));
System.out.println("OR(dictionary, index): " +
    engine.searchOR(new String[]{"dictionary", "index"}));
System.out.println("Rank(search, index): " +
    engine.rankDocuments(new String[]{"search", "index"}));

System.out.println("Remove D3: " + engine.removeDocument("D3"));
System.out.println("AND after removal: " +
    engine.searchAND(new String[]{"search", "algorithms"}));

engine.addDocument("D2",  // same ID: replace old content
    "Java maps map keys to values. " +
    "Maps are useful for dictionary operations and fast lookups.");
System.out.println("D2 search frequency after replacement: " +
    engine.getWordFrequency("search", "D2"));
System.out.println("OR(index): " + engine.searchOR(new String[]{"index"}));
System.out.println("Documents after changes: " + engine.getDocumentCount());
```

**Expected output:**

```text
Documents: 3
D1 search frequency: 3
D1 index frequency: 2
AND(search, algorithms): [D3]
OR(dictionary, index): [D1, D2]
Rank(search, index): [D1, D2, D3]
Remove D3: true
AND after removal: []
D2 search frequency after replacement: 0
OR(index): [D1]
Documents after changes: 2
```

The last five lines show that **removal** clears D3 from search results and **replacement** removes D2's old indexed words rather than appending new content.
