### COSC2007 – Data Structures II
# Assignment: Mini Search Engine

## 🎯 Objective

Build a **document search engine in Java** using dictionaries (`Map`/`HashMap`). Your program will index documents, count words, search with AND/OR queries, and rank results. **You must use dictionaries; you must not implement a hash table yourself.**

!!! abstract "Learning Objectives"
    - Use **nested dictionaries** to maintain a document index and an inverted index.
    - Apply **set operations** to answer multiword searches.
    - Keep multiple data structures consistent when documents are replaced or removed.

!!! note "Marks and deadline"
    **100 marks.** Check the course LMS for the due date and submission location.

## 📋 Required Data Structures

Maintain both dictionaries (provided in the starter):

```java
Map<String, Map<String, Integer>> documentIndex; // doc ID -> (word -> count)
Map<String, Map<String, Integer>> invertedIndex; // word -> (doc ID -> count)
```

For `D1 = "Java java data"`, the entries include:

```text
documentIndex: D1   -> {java=2, data=1}
invertedIndex: java -> {D1=2}
               data -> {D1=1}
```

## 💻 Methods to Implement

| Method | Required behavior |
|---|---|
| `void addDocument(String id, String content)` | Index a document. If `id` already exists, **fully replace** its old content and index entries. |
| `boolean removeDocument(String id)` | Delete the document and its inverted-index entries. Return `true` if found, otherwise `false`. |
| `int getWordFrequency(String word, String documentId)` | Return the normalized word's count in that document; `0` if absent. |
| `List<String> searchAND(String[] queryWords)` | Return IDs containing **every** distinct query word. |
| `List<String> searchOR(String[] queryWords)` | Return IDs containing **at least one** query word. |
| `List<String> rankDocuments(String[] queryWords)` | Rank matching IDs by **sum of frequencies** of distinct query words (highest first). |
| `int getDocumentCount()` | Return number of stored documents, including empty ones. |
| `int getVocabularySize()` | Return number of distinct words across all current documents. |

### 🚦 Input and Output Rules

- **IDs:** Case-sensitive (`"D1"` differs from `"d1"`). Null or blank IDs (`"  "`) throw `IllegalArgumentException`. IDs are otherwise preserved as given.
- **Content:** Null throws `IllegalArgumentException`; an empty or punctuation-only document is allowed and still counts as one document.
- **Words:** A word is a consecutive sequence of English letters or digits (`[A-Za-z0-9]+`). Convert words to lowercase; punctuation/whitespace separate words. Thus `"Java, JAVA!"` has `java` twice, and `"don't"` becomes `don`, `t`.
- **Queries:** Each array element may contain multiple words. Ignore null elements and punctuation-only elements; count repeated query words **once**. A null query array throws `IllegalArgumentException`.
- **Frequency input:** `word` must not be null or contain more than one word after tokenization (`IllegalArgumentException`). Punctuation-only input returns `0`.
- **Ordering:** AND and OR return document IDs in **ascending lexicographic order**. Ranking sorts by **descending score**, then **ascending document ID** for ties. No matches or no query words produce `[]`.

!!! warning "Important"
    When replacing or removing a document, remove its old references from **both indexes**. If a word has no remaining documents, remove that word from `invertedIndex` entirely.

## 🧪 Example Run

```java
MiniSearchEngine engine = new MiniSearchEngine();
engine.addDocument("D1", "Data structures use dictionaries");
engine.addDocument("D2", "Dictionaries make searching fast");
engine.addDocument("D3", "Data searching uses algorithms");

System.out.println(engine.searchAND(new String[]{"dictionaries", "searching"}));
System.out.println(engine.searchOR(new String[]{"data", "searching"}));
System.out.println(engine.rankDocuments(new String[]{"data", "searching"}));
System.out.println(engine.getWordFrequency("DATA!", "D1"));
System.out.println(engine.getDocumentCount());

engine.addDocument("D2", "Data data searching"); // replaces D2
System.out.println(engine.getWordFrequency("data", "D2"));
System.out.println(engine.searchAND(new String[]{"dictionaries", "searching"}));
```

**Expected output:**

```text
[D2]
[D1, D2, D3]
[D3, D1, D2]
1
3
2
[]
```

For ranking, the score is the **total number of occurrences** of distinct query words in each document; documents with a score of `0` are excluded.
